# Robin Canovas — Portfolio (React)

Vite · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · Lucide.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static output in dist/
```

All content lives in `src/data/profile.ts` (experiences, projects, education, links).
Company logos are generated SVG monograms (`CompanyLogo` in `src/components/ui.tsx`) — replace with official logos when available.
